# 实验室出国参会与报销指南（计算机学院）

> 整理日期：2026-07-24。学校政策、办理地点、电话和表格可能更新，办理前务必打开文末官方链接复核。
>
> 本文是实验室经验整理，不能替代学校正式通知和审批要求。

## 总流程

出国前先完成保密/公开发表信息审核、GMS 学校公派申请和出国（境）申请审批；出国时留好会议证明、机酒票据和付款记录；回国后在 GMS 登记回国信息并导出或填写费用结算单，盖章、预约报账、研究生院签字，最后在资助投递机投递材料。

## 时间提醒

- 出国（境）审批原则上至少提前 3–4 周办理，并自行跟进审批流程。
- 研究生院资助申请一般要求在研究生教育系统中提前发起申请；官方通知提到“提前 3 周”。
- 回国后尽快办理报账。研究生院资助通知提到回境后 2 周内办理报账手续；国际处页面也提示出访结束后及时完成出访总结/审核。

## 出国前

### 1. 办理公开发表信息审核

准备并办理《北京理工大学公开发表著作和论文保密审查表》。

- [公开信息及公开发表论文、专利保密审核表单](https://mse.bit.edu.cn/xzzq/kxyja/ee26e3ef3a424c0d86a58380c936d158.htm)

线下办理经验：

1. 去 1430 找张艳老师。
2. 如果老师不在，可以放在桌上，并请老师帮忙留言。
3. 完成线上备案。
4. 去中教一层保密办第二间办理后续手续。

### 2. 确认护照、签证和保险

- 护照、签证按会议和目的地要求提前准备。
- 保险必须覆盖完整出访期间，包括路途时间。
- 如果签证或入境材料需要学校证明，按国际处说明办理，不要等到临出发。

### 3. 查报销额度和资助额度

- [因公出国（境）开支标准](https://international.bit.edu.cn/ygcj/glxx/kzbz/2554c1bbf9e1431d9e4c5a3cb7e73f6e.htm)
- [资助研究生出国（境）参加学术会议与短期交流的通知](https://grd.bit.edu.cn/gjjl/xnlhpyxm/bslc_xn/168e55f849084539aa3f8c5678d61d02.htm)

做预算时区分导师资助、研究生院资助以及可能的学院或其他资助。

### 4. 在 GMS 提交学校公派申请

入口：[GMS 研究生管理系统](https://gms.bit.edu.cn/)

路径：国际交流 → 学校公派申请。

按系统要求提交国际会议或学术交流申请材料。

### 5. 在 GMS 提交出国（境）申请

入口：[GMS 研究生管理系统](https://gms.bit.edu.cn/)

路径：国际交流 → 出国（境）申请。

这一步必须审批通过才能出国，否则回国后可能无法报销。填报时重点注意：

1. 日程安排中，会议日期之外最多能在国外停留 3 天，且包括路途中的时间；常见安排是“前二后一”或“前一后二”。
2. 邀请信中应出现“海报、展板、口头发言”等能证明参会形式的文字；如果没有，联系会务重发邀请信。
3. 保险覆盖完整出访期间。
4. 根据实际情况申请导师资助和研究生院资助。
5. 如果申请了导师或校内部门资助，审批通过后会提供经费卡号，后续报销会用到。
6. 如果乘坐非国内航空公司航班，审批时按实际情况填写；否则可能还需要补充《乘坐非国内航空和更改中转地申请表》。

### 6. 出发前材料自查

- 保密审查表及相关备案/审批记录。
- 护照、签证、保险。
- 邀请信、录用证明、会议日程，且邀请信中有报告形式说明。
- GMS 学校公派申请审批通过记录。
- GMS 出国（境）申请审批通过记录。
- 学生出国（境）证明，按学校要求领取或后续报销时领取。
- 资助经费卡号，包括导师经费卡和研究生院资助经费卡。
- 预算额度截图或官方标准链接。

## 出国中

1. 会议期间拍照留证，至少保留能证明本人实际参会的照片。
2. 酒店索要 invoice 和水单或账单明细。
3. 机票、行程单、登机牌和支付记录都要留好。
4. 各项支出留好发票，同时保存订单截图和付款截图。
5. 机票行程尽量和 GMS 出国（境）申请登记的一致；不一致时可能需要补审批或补说明。
6. 严格按审批时间、城市和任务执行，不要无故超期、增加未审批城市或更改任务。

## 回国后

### 1. 整理票据和证明材料

报销材料不只需要发票，还要准备订单截图、付款截图和行程证明。建议按类别整理：

- 机票、行程单、登机牌、付款截图。
- 酒店 invoice、水单或账单明细、付款截图。
- 注册费 invoice/receipt、订单截图、付款截图。
- 签证费、保险费、交通费等其他可报销项目的票据和付款证明。
- 会议证明：参会照片、Accepted Papers 官网截图、会议日程、报告安排等。
- 出国（境）审批记录、学生出国（境）证明、费用结算单和报账单。

### 2. 在 GMS 登记回国信息

入口：[GMS 研究生管理系统](https://gms.bit.edu.cn/)

路径：国际交流 → 出国（境）申请。

操作顺序：

1. 先点击确认出国（境）有无变更。
2. 如果没有变更，选择“没变更”。
3. 系统出现“回国（境）管理”后，登记回国信息。

填报时注意：

1. 包干项目中填写“每日额度 × 天数”之后的金额。
2. “是否录入论文集”的证明材料，可以提交会议官网 Accepted Papers 截图。
3. 如果实际行程、航司、城市或日期和原审批不一致，先按系统和学院/国际处要求补变更或说明。

### 3. 获取费用结算单并盖章

回国（境）管理审批流程完成后，可以从系统导出费用结算单；也可以在国际处页面下载学生版本的[北京理工大学因公出国（境）费用结算单](https://international.bit.edu.cn/ygcj/glxx/hgbx/d2d2f00b53594c5e9cf9bf80a3bd1526.htm)。

填写或核对重点：

1. 费用结算单中的实际停留天数必须和出国日期对应。
2. 系统导出的结算单可能会减去路途天数，需要手动核对并调整。
3. 拿费用结算单和所有报销材料去学生服务中心（图书馆旁边）国际处盖章；国际处外出时间以当日通知为准。
4. 同时向国际处领取学生出国（境）证明。

### 4. 预约报账并处理报账单

报账单和费用结算单不是同一个东西。费用结算单可能有多张，报账单按经费来源分别准备。

费用结算单盖章后，请导师预约报账。如果申请了研究生院资助，通常需要分别处理：

1. 导师经费卡对应的报账单。
2. 研究生院资助经费卡对应的报账单。

研究生院资助经费卡号可在 GMS 出国（境）申请中查询；导师经费卡号向老师确认。

### 5. 研究生院资助报账单签字

拿着研究生院资助对应的报账单和其他材料，按当前通知前往研究生院指定地点签字。原经验记录为研究生楼 317 林旷世老师；老师、地点或流程可能变化，应以[研究生在线办理出国（境）学术交流流程](https://grd.bit.edu.cn/gjjl/xnlhpyxm/bslc_xn/670c69db722b42f595fe299dc629ce5f.htm)页面中的信息为准。

### 6. 投递材料

所有流程完成后，在资助投递机中投递材料。

投递前最后检查：

- 发票、invoice、receipt 是否齐全。
- 订单截图和付款截图是否齐全。
- 机票和行程单是否齐全。
- 酒店水单或账单明细是否齐全。
- 费用结算单是否盖章，实际停留天数是否正确。
- 学生出国（境）证明是否齐全。
- 各张报账单是否齐全，需要签字的地方是否已签。
- 研究生院资助报账单是否已按当前流程签字。

## 常见坑位

- 出国（境）申请必须提前办理，不能先出国再补审批。
- 会议之外停留天数要控制，路途时间也算在内。
- 邀请信应体现参会形式，如海报、展板或口头发言。
- 保险覆盖时间不能漏掉路途。
- 机票尽量与审批信息一致，不一致会增加补审批或补说明成本。
- 报销不只看发票，还需要订单截图、付款截图和酒店水单等证明。
- 系统导出的费用结算单可能少算路途天数，要人工核对实际停留天数。
- 导师资助和研究生院资助可能对应不同经费卡号和报账单。
- 回国后不要拖延，研究生院资助可能要求回境后 2 周内办理报账。
